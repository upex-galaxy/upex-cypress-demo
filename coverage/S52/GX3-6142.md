# ⚡️ToolsQA | Elements | Buttons

User Story [GX3-6142](https://upexgalaxy-v10.atlassian.net/browse/GX3-6142)

✔ Description

    Como: Usuario web de https://www.saucedemo.com/,
    Quiero: iniciar sesión en el website,
    Para: poder tener acceso a realizar compras en la página.

✅ ACCEPTANCE CRITERIA

    Feature: Account | Iniciar Sesión
  
        Background:
            Given el usuario tiene una cuenta registrada
            And el usuario está situado en la página de Login

        Scenario: usuario inicia sesión
            When el usuario completa el formulario de inicio de sesión correctamente
            And hace click en el botón "login"
            Then el usuario debe iniciar sesión exitosamente
            And debe ser redirigido al PLP pudiendo ver todos los items disponibles

        Scenario: usuario no puede iniciar sesión
            When el usuario completa el formulario de inicio de sesión con credenciales invalidas
            And acciona el botón "login"
            Then el usuario debe permanecer en el inicio de sesión
            And el mensaje de error "Username and password do not match any user in this service" debe mostrarse

        Scenario: usuario bloquedo intenta iniciar sesión
            Given el usuario que intenta iniciar sesión ha sido bloqueado
            When el usuario completa el formulario de inicio de sesión
            And hace click en el botón "login"
            Then el usuario debe permanecer en el inicio de sesión
            And el mensaje de error "Sorry, this user has been locked out" debe mostrarse

        Scenario: usuario intenta iniciar sesión con campos vacíos en el formulario
            When el usuario hace click en el botón "LOGIN" sin haber ingresado nada en los campos
            Then el sistema debe denegar el acceso del usuario al PLP
            And debe aparecer un mensaje amigable por campo requerido

    Feature: No Authentication Access

        Scenario: usuario intenta ingresar a un endpoint de la website sin haber iniciado sesión.
            Given el usuario NO ha iniciado sesión en la website de SwagLabs
            When ingresa a un endpoint de la website que requiere autorización
            Then el usuario debe ser redirigido a la página de Login
            And debe desplegarse el mensaje "You can only access 'endpoint' when you are logged in."

🚩BUSINESS RULES SPEC
     ____________________________________________________________________________________________________________________________________________
    | BR | ACTION                                                   | RESPONSE                                                                   |
    | 1  | Inicio de sesión con username bloqueado.                 | Epic sadface: Sorry, this user has been locked out.                        |
    | 2  | Inicio de sesión fallido (Not match)                     | Epic sadface: Username and password do not match any user in this service  |
    | 3  | Inicio de sesión fallido (Null username)                 | Epic sadface: Username is required                                         |
    | 4  | Inicio de sesión fallido (Null password)                 | Epic sadface: Password is required                                         |
    | 5  | Inicio de sesión fallido (Null username + Null password) | Epic sadface: Username is required                                         |
    ----------------------------------------------------------------------------------------------------------------------------------------------
    La BR5 aplica de tal manera porque el Username es el que define la Cuenta del Usuario y es el primer match de la Database.

    No Authentication Access
        Si un usuario intenta acceder a algún endpoint de la web sin haber iniciado sesión deberá mostrarse el mensaje “You can only access 'endpoint' when you are logged in.“

        Endpoints existentes en la web:
            * /inventory.html
            * /cart.html
            * /checkout-step-one.html
            * /checkout-step-two.html
            * /checkout-complete.html
